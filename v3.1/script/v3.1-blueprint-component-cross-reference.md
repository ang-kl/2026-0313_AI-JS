# v3.1 Blueprint Element x Website Component Cross-Reference

**Audit date:** 27-08-2026
**Scope:** v3.1 Step 1, Step 2, Work Universe landing, Review Studio workspace, and the blueprint MVP phases in `goal/v3-blueprint.md` and `goal/v3-ui-blueprint.md`.  
**Rule:** a component is `BUILT` only when it is rendered and usable. Source code, a label, or a placeholder is not enough.

## Status key

| Status | Meaning |
|---|---|
| `BUILT` | Rendered, interactive, and backed by a real data or state contract. |
| `WIRED` | An existing built component is reached from the new Work Universe route. |
| `PARTIAL` | The useful core exists, but the blueprint asks for more. |
| `PARKED` | The current Step 3 spec explicitly says this is not shipped yet. |
| `WITHHELD` | The UI exists and correctly refuses to invent a value without evidence. |

## Honest completeness conclusion

The established Role Work Universe MVP is now built and linked to the existing v3.1 evidence workspace. The full v3 blueprint is **not** complete. The largest remaining product blocks are the occupation-sensitive visual grammar, dedicated workflow/value-stream maps, person-evidence ingress and cover-letter workflow, and the governance/disagreement layer.

The next build should start with the **Workflow Map**, because the Organisation Map now covers the blueprint's ownership-and-structure question while sequence, decisions, handoffs and role-sensitive process flow remain parked.
