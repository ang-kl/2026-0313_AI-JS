# v3.1 Organisation Map · Agent and Human-Reserved Economies

**Blueprint basis:** `goal/v3-blueprint.md` §10.3 and `goal/v3-ui-blueprint.md` §6.2.

**Accepted UI basis:** user-supplied organisation-chart and professional charting references, 27-08-2026.

## Presentation contract

- Use a quiet dotted canvas, white rounded cards, thin blue curved connectors, muted navy text and restrained purple/cyan accents.
- The role is a view anchor, not an organisation node and not a reporting claim.
- Nodes represent only supplied functions, teams, roles or boundaries.
- Parent and relationship connectors render only from explicit payload fields.
- The six blueprint dimensions remain usable below the chart.
- The Organisation Work Graph route continues to Organisation Map, then AI Moments, then Cards | Business cube.

## Work-allocation contract

Each supplied organisation node may include explicit `agentEconomy` / `agent_economy` and `humanReservedEconomy` / `human_reserved_economy` arrays. Equivalent nested `economy.agent` and `economy.humanReserved` fields are accepted.

Agent-economy work is `GOVERNED` only when the item supplies:

1. source evidence;
2. a named human owner; and
3. a governance reference or approval mode.

Otherwise the supplied candidate remains visible as `BLOCKED`; it is not promoted as deployable work.

Human-reserved work is `RESERVED` only when the item supplies source evidence and an explicit reserved reason. Otherwise it remains visible as `UNCONFIRMED`. No work is classified as human-reserved from title, keywords, exposure bands, or model intuition.

No economy percentage, workforce share, headcount effect or maturity score is calculated.

## Empty-state contract

- No nodes/functions: withhold the chart and explain that title is not structure.
- No parent/relationship fields: draw no connectors.
- No economy arrays: show both economy zones as `WITHHELD`.
- Missing item governance/evidence: show `BLOCKED` or `UNCONFIRMED`, never silently complete the claim.

## Non-regression boundary

This slice does not change Step 1, Step 2, Work Universe projection algorithms, Role Graph/FAB integration, Workflow Map, Value Stream Map, Print/PDF, AI Moments analysis, `v3/`, or the Railway root.
