How to read this map

Pink numbers identify visible interface features. Every callout resolves to an immutable FEAT-… record in the JSON manifest. The feature then references its owning CMP-…, relevant STATE-…/TRANS-…, source PAY-… fields, and testable INV-… rules.

Evidence boundary. These images are deterministic test fixtures captured from local baseline d250c36. They verify layout and behavior under controlled payloads; they are not proof that this commit is deployed or that current live postings supply every optional field.

Material invariants
