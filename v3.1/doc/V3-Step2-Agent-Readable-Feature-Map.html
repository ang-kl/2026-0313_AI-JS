Payload Boundaries

PAY-STEP2-MCF-001 / PAY-STEP2-CAREERS-001

Source postings

Missing source rows produce empty source panels or error states. The client must not fabricate postings, salary, employer, dates or links.

PAY-STEP2-SSOC-001

SSOC classification

Missing classification remains Unclassified/withheld. The map explicitly forbids inferred SSOC, ISCO and AI exposure evidence.

PAY-STEP2-POSTING-001

Selected posting

The selected-posting handoff carries the posting payload, not just the query title.

PAY-STEP2-EMPLOYER-001

Employer registry

Only exact ACRA matches are displayed as registered employer evidence; no address is inferred from job-ad text.
