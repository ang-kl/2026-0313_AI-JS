1. Why this, why now

A live, clickable prototype at v3.takearoundabout.com/demo has proven the shape end-to-end across PRs #159–#178 (v3.0.96→v3.0.115). This plan turns that prototype into a real, additive feature in the v3 app — without disturbing the existing result engine or the landing page.

2. The honesty contract — how much is deterministic

The single most important rule: the engine authors every number and verdict; the LLM only narrates; nothing is fabricated (withheld instead). Every line in the feature must carry a provenance chip matching its tier.

TierChipWhat it coversReproducible?
Verbatim● from postingJob-ad facts: title, employer, salary, experience, qualifications; SGDI org structure; live careers.gov.sg rolesYes — copied
Computed✓ computedAI-exposure index + resilience (SSOC→ISCO→SOC→AIOE); ESCO/ISCO mappings; the headline numbersYes — same input → same output
Derived◐ derivedPattern counts ("seen in 2 of 2 ads"), demand recency, salary percentiles — counts over the corpus (a rough read)Yes — for this sample
Advisory~ AI estimateNarration; the journey prose; value-stream tags; ecotone realm; positioning; the 7/14/30 plan; the next-move sentence (the pick is computed, the words advisory)No — varies; withheld if unsupported
Candid flag. The candidate/organisation journeys lean on the advisory tier more than today's result page does. Discipline for the build: every journey line must trace to a deterministic fact or carry a ~ chip, and the edge / value-stream reads need a real derivation rule, not just LLM prose.

+--------------------------------------------------------------+
  • Radial focus-browser — one centre, tap a bubble to re-centre (depth loops); path shrinks into a trail; labels word-wrap, never truncate.
  • Ecotone overlay toggle — nodes tinted internal (blue) / edge (amber glow) / external (teal); boundary-crossing links emphasised.
  • Lens toggle — Candidate vs Organisation changes the panel content, not the graph.
  • Styling: the existing v3 neumorphic soft-UI, navy header, #e6ebf2, NEO shadows. No red/green.

  • npm run build green; R-FREEZE byte-identical; conformance-auditor + a11y-honesty-reviewer PASS before each version bump.
  • Determinism snapshot: same posting → identical engine output (the headline numbers).
  • Live check on v3.takearoundabout.com after merge: a role shows the candidate journey grounded in real engine output; a department shows the value stream; provenance chips present on every line.
